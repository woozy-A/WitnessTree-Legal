개인정보 처리방침지원

1. 한눈에 보기

오랜나무는 전국의 오래된 나무와 장소의 시간을 탐색하는 앱입니다. 광고 추적이나 개인정보 판매를 하지 않습니다. 로그인 없이 이용할 수 있으며, 사진을 제출하면 익명 사진 계정을 사용합니다. 선택 로그인으로 기록 백업을 사용하면 방문·저장 기록도 본인 계정에 연결해 Supabase에 보관합니다.

2. 처리하는 정보

기기에만 남는 정보

  • 로그인하지 않은 상태의 저장·방문 기록, 아직 전송하지 않은 사진
  • 계정에 로그인하면 기존 비회원 기록을 연결합니다. 이미 다른 계정이 있는 경우에는 화면의 안내에 따라 비회원 기록을 기기에 별도로 보관할 수 있습니다.

로그인과 기록 백업 시 처리하는 정보

  • 카카오 또는 Apple 인증으로 확인된 사용자 식별자, 인증 세션과 제공자 정보
  • 기존 익명 사진 계정을 카카오에 연결할 때 동의받는 인증된 카카오계정 이메일. 계정 연결과 관리에 사용하며 마케팅에는 사용하지 않습니다.
  • Apple 로그인에서 동의받는 이메일 또는 Apple이 제공하는 가상 이메일 주소. 같은 계정 연결·관리 용도로 사용합니다.
  • 저장한 나무 ID·저장일, 방문한 나무 ID·방문일·방문 확인 방식·날짜의 시간대
  • 기기 간 동기화에 필요한 작업 식별자와 삭제 표시

방문 백업에는 기기의 GPS 좌표와 이동 경로를 전송하지 않습니다. 다만 방문한 나무 ID와 날짜를 보관하므로 방문 장소와 시기를 알 수 있습니다. 개인 방문·저장 기록은 다른 사용자에게 공개하지 않습니다.

온라인 사진 등록 시 처리하는 정보

  • Supabase가 만든 익명 사용자 식별자와 로그인 세션
  • 제출 사진, 나무 식별자, 촬영 시기와 그 근거·정밀도, 제출 시각
  • 사진 출처, 공개 권한 확인, 검수 상태, 신고·개인 차단 기록
  • 위치 확인을 요청한 경우 나무 주변 촬영 여부의 범주형 결과

정확한 GPS 좌표나 이동 경로는 공개 DB에 저장하지 않습니다. 승인 사진은 EXIF·GPS·촬영자 이름 등 이미지 메타데이터를 제거한 사본만 공개합니다.

3. 이용 목적

  • 사진 제출자를 구분하고 본인 기록만 관리하도록 권한을 적용
  • 인증된 이메일로 기존 익명 사진 계정에 로그인 신원을 연결하고 계정을 관리
  • 본인 계정의 방문·저장 기록과 서버에 남은 사진을 다른 기기에서 복원
  • 관리자 검수 후 나무별 시간 갤러리에 승인 사진 공개
  • 오용·스팸 방지, 신고 처리, 서비스 안정성 유지

4. 보관과 삭제

  • 검수 전 원본은 비공개 저장소에 보관하며 승인·거절·차단 또는 사용자의 철회 뒤 삭제합니다.
  • 승인된 사진은 메타데이터가 제거된 공개 사본으로 보관하며, 사용자가 사진 삭제 또는 계정 삭제를 실행하면 공개 기록과 저장소에서 제거합니다.
  • 로그인 계정 삭제는 계정의 방문·저장 기록, 동기화용 삭제 표시·작업 기록과 제출한 서버 사진을 삭제합니다. 현재 기기의 해당 계정 기록도 함께 지웁니다. 오프라인 상태인 다른 기기의 캐시는 해당 기기에서도 삭제해야 합니다.
  • 비회원의 온라인 사진 계정 삭제는 익명 인증 계정과 서버 사진을 삭제하며 기기의 방문·저장 기록은 유지합니다.
  • 로그아웃은 삭제가 아닙니다. 계정별 기기 캐시는 분리해서 보관하고 같은 계정으로 로그인했을 때만 다시 표시합니다. 미전송·거절·차단 사진 원본은 서버 복원을 보장하지 않습니다.
  • 삭제된 공개 파일은 CDN 캐시 갱신 때문에 짧은 시간 이전 URL에서 보일 수 있습니다.

5. 처리 위탁과 국외 이전

인증, 데이터베이스와 사진 저장을 위해 Supabase를 사용합니다. 오랜나무의 서버 프로젝트는 대한민국 서울 리전에 구성되어 있습니다. Supabase의 서비스 운영 과정에서 기술 로그 등은 해당 사업자의 정책에 따라 처리될 수 있습니다.

6. 이용자의 선택과 권리

  • 대기 사진: 나무 상세의 기록 삭제
  • 승인된 내 사진: 사진을 길게 눌러 내 사진 삭제
  • 익명 계정과 서버 사진 전체: 나의 나무 → 데이터 및 개인정보 → 온라인 사진 계정 삭제
  • 로그인 계정과 기록 전체: 나의 나무 → 나의 계정과 백업 → 계정과 나의 기록 삭제
  • 다른 사람의 사진: 신고 또는 내 화면에서 가리기
